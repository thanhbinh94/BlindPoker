> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. The web task (Task 5) MUST load `frontend-design:frontend-design` and follow the Design Brief in Plan 3 (`docs/superpowers/plans/2026-09-04-plan3-ui-kit.md`).

**Goal:** Ship the Lite edition: one process that serves the web UI, the REST endpoints (session by display name, profile, daily reward, relief, health, config) and the WebSocket game server from `@bp/server-kit`, persisting to SQLite through `node:sqlite`, packaged as a single `bind-poker-lite.exe` for Windows x64 via Node SEA (no Node.js on the target host), with a footprint test proving Normal-only dependencies are absent.

**Architecture:** `apps/lite` has two roots: `server/` (Node, bundled by esbuild into one CJS file) and `web/` (React + `@bp/ui-kit`, built by Vite into static files). At runtime the server serves the static files either from SEA assets (`process.getBuiltinModule('node:sea')`) or from `dist/public` on disk (dev). Persistence implements the three `@bp/server-kit` repository interfaces over `DatabaseSync` with real transactions, per-player netting and sink rows. Identity is a display name + random token (`SessionResolver.fromToken`). Economy (daily reward, relief) lives in the app and pushes `BALANCE` via `GameServer.balanceChanged`. Graceful shutdown follows `docs/server-kit.md` (SIGTERM/SIGINT → `stopAccepting` → drain → close, ≤ 10 s).

**Tech Stack:** Node 22.13 (`node:sqlite`, `node:sea`), Fastify 5, ws 8, React 18 + `@bp/ui-kit`, Vite 5, esbuild 0.24, postject 1.0.0-alpha.6, Vitest 2, Playwright (optional e2e script, not part of `pnpm test`).

**Spec:** `docs/superpowers/specs/2026-09-04-bind-poker-design.md` §10.2 (Lite profile), §12.4 (relief), §13.3 (Lite daily), §18.3 (Lite DB), §19.1/§19.3 (REST), §22.4–22.5 (build, env), §27.2 (screens for Lite), §28.2 (deployment), §29.5 (Lite tests), §30 (server restart), §32 (assumptions 10–11).

## Global Constraints

- Node `>=22.13`, pnpm 9 (`export PATH="$PATH:$(npm prefix -g)"` in bash when missing).
- `@bp/lite` `dependencies`: `@bp/core`, `@bp/server-kit`, `@bp/ui-kit`, `fastify`, `react`, `react-dom`. No `pg`, `drizzle-orm`, `argon2`, `react-router`, `better-sqlite3`, `pino-pretty`; no other native module. A footprint test enforces it on the built bundle.
- No `EDITION` switches anywhere; Lite is a separate app composing shared packages. `tooling/arch/boundaries.test.ts` allows `@bp/lite → core, server-kit, ui-kit`.
- All money changes go through `BalanceRepository.apply` (atomic transaction, per-player netting, sink rows per `docs/server-kit.md` "Repositories"). Balances never negative. Daily/relief use the same path.
- REST: JSON; errors `{ error: { code, message } }`; mutating routes require header `X-Requested-With: bind-poker`; bearer token `Authorization: Bearer <token>`; rate limit login/session creation 10/min/IP (simple in-memory bucket).
- Web: no hard-coded UI strings (`react/jsx-no-literals` applies to `apps/**`), Lite namespace `lite` via `createI18n({ extraResources })`, no external fonts, theme + language persisted in `localStorage` (`bp.theme`, `bp.lang`), session token in `localStorage` (`bp.lite.token`). Token flow: `useGameClient({ autoConnect: false })` until a token exists, then `connect()`.
- Budgets: web JS ≤ 250 KB gzip, CSS ≤ 40 KB gzip; exe ≤ 120 MB; startup < 2 s.
- Config via env (`PORT`, `HOST`, `SQLITE_PATH`, `LITE_HAND_LOG`, `LOG_LEVEL`, `ECONOMY_TIMEZONE`, `ALLOWED_ORIGINS`), read from process env and from a `.env` file next to the executable (or cwd in dev). No secrets required for Lite.

```ts
import { dirname } from 'node:path'

export interface LiteConfig { port: number; host: string; sqlitePath: string; handLog: boolean; logLevel: 'debug' | 'info' | 'warn' | 'error'; timezone: string; allowedOrigins: string[] | null; publicDir: string | null }

export const DEFAULT_CONFIG: LiteConfig = { port: 8080, host: '0.0.0.0', sqlitePath: './bind-poker.sqlite', handLog: false, logLevel: 'info', timezone: 'Asia/Ho_Chi_Minh', allowedOrigins: null, publicDir: null }

export function parseDotenv(text: string): Record<string, string> {
  const out: Record<string, string> = {}
  for (const raw of text.split(/\r?\n/)) {
    const line = raw.trim()
    if (!line || line.startsWith('#')) continue
    const eq = line.indexOf('=')
    if (eq <= 0) continue
    const key = line.slice(0, eq).trim()
    let value = line.slice(eq + 1).trim()
    if ((value.startsWith('"') && value.endsWith('"')) || (value.startsWith("'") && value.endsWith("'"))) value = value.slice(1, -1)
    else { const hash = value.indexOf(' #'); if (hash >= 0) value = value.slice(0, hash).trim() }
    out[key] = value
  }
  return out
}

const LEVELS = new Set(['debug', 'info', 'warn', 'error'])
function validTimezone(tz: string): boolean { try { new Intl.DateTimeFormat('en-US', { timeZone: tz }); return true } catch { return false } }

export function loadConfig(env: Record<string, string | undefined>, dotenvText?: string): LiteConfig {
  const file = dotenvText ? parseDotenv(dotenvText) : {}
  const get = (k: string) => env[k] ?? file[k]
  const port = get('PORT') === undefined ? DEFAULT_CONFIG.port : Number(get('PORT'))
  if (!Number.isInteger(port) || port < 0 || port > 65535) throw new Error(`PORT must be an integer 0–65535, got ${get('PORT')}`)
  const logLevel = (get('LOG_LEVEL') ?? DEFAULT_CONFIG.logLevel) as LiteConfig['logLevel']
  if (!LEVELS.has(logLevel)) throw new Error(`LOG_LEVEL must be one of ${[...LEVELS].join(', ')}`)
  const timezone = get('ECONOMY_TIMEZONE') ?? DEFAULT_CONFIG.timezone
  if (!validTimezone(timezone)) throw new Error(`ECONOMY_TIMEZONE is not a valid IANA zone: ${timezone}`)
  const origins = get('ALLOWED_ORIGINS')
  return {
    port,
    host: get('HOST') ?? DEFAULT_CONFIG.host,
    sqlitePath: get('SQLITE_PATH') ?? DEFAULT_CONFIG.sqlitePath,
    handLog: ['1', 'true', 'yes'].includes((get('LITE_HAND_LOG') ?? '').toLowerCase()),
    logLevel,
    timezone,
    allowedOrigins: origins ? origins.split(',').map((s) => s.trim()).filter(Boolean) : null,
    publicDir: get('PUBLIC_DIR') ?? null,
  }
}

export function resolveBaseDir(): string {
  const sea = process.getBuiltinModule('node:sea') as { isSea(): boolean } | undefined
  return sea?.isSea() ? dirname(process.execPath) : process.cwd()
}
```
