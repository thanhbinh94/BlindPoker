# Plan 25 — GM role, round 1 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Before Task 1, run the pre-flight review CLAUDE.md §7 asks for (an independent opus subagent reads this plan against the real code) and splice its amendments in as "Amendments (pre-flight 2026-10-18)".

**Goal:** A `gm` role on Normal accounts with an immutable action log, `/api/gm/*` routes to search players, move points, grant items, lock accounts and manage live rooms, and a `#/gm` screen only GMs see.

**Architecture:** Two columns and a table in PostgreSQL (`users.role`, `users.locked_at/locked_reason`, `gm_actions`); a `requireGm` guard that re-reads the role on every request; a `GmService` that writes each action and its effect in one transaction and reuses `creditWithin` for points; two small additions to `@bp/server-kit` (`Gateway.disconnect`, `Room.adminKick`/`adminSummary`) so a route never touches room internals; a lazily loaded `GmScreen` in normal-web reached from Settings.

**Tech Stack:** TypeScript, Fastify 5, Drizzle + pg (PGlite in tests), React 18 + i18next, Vitest, Playwright (ops pack). No new dependency.

**Spec:** `docs/superpowers/specs/2026-10-18-gm-role-design.md` (Vietnamese; the Q-table is binding).

**Branch:** `feature/BP-25-gm-role` in `.worktrees/BP-25` (own `pnpm install`; on this machine `corepack pnpm`, with the pnpm shim on PATH for root scripts — see `docs/lessons-learned.md`, BP-24).

## Review Focus

1. **A GM's cookie outliving a demotion** — the next `/api/gm/*` request after `role` flips to `player` must be 403 and the screen must leave `#/gm`; pinned in Task 2 (guard) and Task 8 (screen).
2. **A locked player mid-hand** — the lock must not cash the stack out before the hand ends; the seat folds and the stack returns at hand end via `adminKick`'s after-hand path; pinned in Task 3 and Task 5.
3. **A negative adjustment larger than the balance** — all-or-nothing: no `gm_actions` row, no ledger row, `409 INSUFFICIENT_BALANCE`; pinned in Task 4.
4. **The last GM demoting themselves or being demoted** — `403` for self, `409 LAST_GM` for the last one, even under two concurrent requests (row lock on `users`); pinned in Task 4.
5. **A room closed while a player's buy-in is pending** — `Room.shutdown` already refunds pending buy-ins; the route reports `refunded` as the number of humans it settled; pinned in Task 5's room test.

```ts
export function createRequireUser(deps: AuthGuardDeps): RequireUser {
  return async (req) => {
    const token = readSessionCookie(req)
    const session = token === null ? null : await deps.sessions.resolve(token)
    if (session === null) throw new HttpError(401, 'UNAUTHENTICATED', UNAUTHENTICATED)
    const auth = await deps.repos.players.findAuth(session.userId)
    // A locked account's sessions were revoked when it was locked; a cookie that still resolves is a race,
    // and the answer is the same as for any dead session: sign in again (and then meet ACCOUNT_LOCKED).
    if (auth === null || auth.lockedAt !== null) throw new HttpError(401, 'UNAUTHENTICATED', UNAUTHENTICATED)
    req.user = { userId: session.userId, playerId: auth.playerId, displayName: auth.displayName, role: auth.role }
  }
}

/** "…and signed in as a GM." The role was read from the database by `requireUser` on this very request. */
export function createRequireGm(requireUser: RequireUser): RequireUser {
  return async (req) => {
    await requireUser(req)
    if (currentUser(req).role !== 'gm') throw new HttpError(403, 'FORBIDDEN', 'this action needs the gm role')
  }
}
```

```ts
function checkReason(reason: unknown): string {
  if (typeof reason !== 'string') throw new ServiceError('INVALID_REASON', 'reason must be a string')
  const trimmed = reason.trim()
  if (trimmed.length < REASON_MIN || trimmed.length > REASON_MAX) throw new ServiceError('INVALID_REASON', `reason must be ${REASON_MIN}–${REASON_MAX} characters`)
  return trimmed
}

async function logAction(tx: AppTx, row: { actorUserId: string | null; action: GmActionKind; targetPlayerId?: string | null; targetRoomId?: string | null; amount?: number | null; itemId?: string | null; reason: string; details?: Record<string, unknown> | null }): Promise<number> {
  const [inserted] = await tx.insert(gmActions).values({ ...row }).returning({ id: gmActions.id })
  return Number(inserted!.id)
}

export function createGmService(deps: GmServiceDeps): GmService {
  const now = deps.now ?? Date.now

  async function target(tx: AppTx | AppDb, playerId: string) {
    if (!isUuid(playerId)) throw new ServiceError('NOT_FOUND')
    const [row] = await tx.select({ id: users.id, role: users.role, lockedAt: users.lockedAt, displayName: players.displayName })
      .from(users).innerJoin(players, eq(players.id, users.id)).where(eq(users.id, playerId))
    if (row === undefined) throw new ServiceError('NOT_FOUND')
    return row
  }

  return {
    async adjustPoints(actor, playerId, amount, reason) {
      const why = checkReason(reason)
      if (!Number.isInteger(amount) || amount === 0 || Math.abs(amount) > POINTS_CAP) throw new ServiceError('INVALID_AMOUNT', `amount must be a non-zero integer within ±${POINTS_CAP}`)
      const result = await deps.db.transaction(async (tx) => {
        const t = await target(tx, playerId)
        const actionId = await logAction(tx, { actorUserId: actor.userId, action: amount > 0 ? 'grant_points' : 'adjust_points', targetPlayerId: t.id, amount, reason: why })
        // `creditWithin` locks the player row, refuses a negative balance (InsufficientBalanceError → the whole
        // transaction, this log line included, rolls back) and writes the ledger row.
        await creditWithin(tx, [{ playerId: t.id, delta: amount, reason: amount > 0 ? 'gm_grant' : 'gm_adjust', refId: `gm:${actionId}` }])
        const [after] = await tx.select({ balance: players.balance }).from(players).where(eq(players.id, t.id))
        return { balance: Number(after!.balance), actionId }
      }).catch((err: unknown) => { if ((err as { name?: string }).name === 'InsufficientBalanceError') throw new ServiceError('INSUFFICIENT_BALANCE'); throw err })
      void deps.game.balanceChanged(playerId)
      deps.game.notify(playerId, { t: 'NOTIFICATION', kind: 'GM_NOTICE', payload: { action: amount > 0 ? 'grant_points' : 'adjust_points', amount, reason: why } })
      return result
    },

    async lock(actor, playerId, reason) {
      const why = checkReason(reason)
      const actionId = await deps.db.transaction(async (tx) => {
        const t = await target(tx, playerId)
        if (actor.userId === t.id || t.role === 'gm') throw new ServiceError('FORBIDDEN', 'a gm cannot be locked; demote first')
        if (t.lockedAt !== null) throw new ServiceError('ALREADY_LOCKED')
        await tx.update(users).set({ lockedAt: new Date(now()), lockedReason: why }).where(eq(users.id, t.id))
        return logAction(tx, { actorUserId: actor.userId, action: 'lock', targetPlayerId: t.id, reason: why })
      })
      await deps.sessions.revokeAll(playerId)
      const room = deps.game.rooms.roomOf(playerId)
      if (room !== undefined) await room.adminKick(playerId).catch(() => undefined) // already gone is fine
      deps.game.notify(playerId, { t: 'NOTIFICATION', kind: 'GM_NOTICE', payload: { action: 'lock', reason: why } })
      deps.game.gateway.disconnect(playerId)
      return { actionId }
    },
    // unlock, setRole (self → FORBIDDEN; demote: `select count(*) from users where role='gm' for update`-free check via
    // `update … where role='gm' and id<>target returning` count ≥ 1 else LAST_GM), grantItem (catalog.get, !free,
    // inventory.grant in tx with GM_ITEM_SOURCE), grantWardrobe (grantAllItems with { tx }), search (ilike on
    // users.email prefix OR players.nameKey contains, ordered by players.id, `before` = last playerId), get,
    // recordRoomAction, actions (joins for actor/target names; `before` = id), overview (counts + ledger.sums(now-24h)).
  }
}
```

```ts
import type { AdminRoomSummary, GameServer } from '@bp/server-kit'
import { ServiceError } from '../errors.js'
export interface GmRoomService {
  list(): AdminRoomSummary[]
  get(roomId: string): AdminRoomSummary | null
  kick(roomId: string, playerId: string): Promise<'now' | 'after_hand'>
  close(roomId: string, reason: string): Promise<{ refunded: number }>
}
export function createGmRoomService(game: Pick<GameServer, 'rooms'>): GmRoomService {
  const must = (roomId: string) => { const r = game.rooms.get(roomId); if (r === undefined) throw new ServiceError('ROOM_NOT_FOUND'); return r }
  return {
    list: () => game.rooms.all().map((r) => r.adminSummary()),
    get: (roomId) => game.rooms.get(roomId)?.adminSummary() ?? null,
    async kick(roomId, playerId) {
      const room = must(roomId)
      if (!room.players.has(playerId)) throw new ServiceError('NOT_IN_ROOM')
      return room.adminKick(playerId).catch((err: { code?: string }) => { throw new ServiceError(err.code ?? 'ILLEGAL_ACTION') })
    },
    async close(roomId, reason) {
      const room = must(roomId)
      const refunded = room.adminSummary().members.filter((m) => !m.isBot).length
      await room.shutdown(`gm: ${reason}`)
      return { refunded }
    },
  }
}
```

```tsx
import { Segmented, type Language } from '@bp/ui-kit'
import { useCallback, useState } from 'react'
import { useTranslation } from 'react-i18next'
import { ApiError, type NormalApi } from '../../api.js'
import s from '../normal.module.css'
import { ActionsTab } from './ActionsTab.js'
import { OverviewTab } from './OverviewTab.js'
import { PlayerDetail } from './PlayerDetail.js'
import { PlayersTab } from './PlayersTab.js'
import { RoomsTab } from './RoomsTab.js'

type Tab = 'overview' | 'players' | 'rooms' | 'actions'
export interface GmScreenProps { api: NormalApi; lang: Language; onForbidden: () => void }

export function GmScreen({ api, lang, onForbidden }: GmScreenProps) {
  const { t } = useTranslation('normal')
  const [tab, setTab] = useState<Tab>('overview')
  const [playerId, setPlayerId] = useState<string | null>(null)
  /** Every tab routes its failures here: a 403 means the role is gone, and the screen leaves. */
  const guard = useCallback((err: unknown): never => {
    if (err instanceof ApiError && err.status === 403) onForbidden()
    throw err
  }, [onForbidden])
  const tabs = (['overview', 'players', 'rooms', 'actions'] as const).map((value) => ({ value, label: t(`gm.tabs.${value}`) }))
  return (
    <main className={s.page}>
      <div className={s.pageHead}><h1>{t('gm.title')}</h1></div>
      <Segmented options={tabs} value={tab} onChange={(next) => { setTab(next); setPlayerId(null) }} label={t('gm.title')} />
      {tab === 'overview' ? <OverviewTab api={api} lang={lang} guard={guard} /> : null}
      {tab === 'players' ? (playerId === null
        ? <PlayersTab api={api} lang={lang} guard={guard} onOpen={setPlayerId} />
        : <PlayerDetail api={api} lang={lang} guard={guard} playerId={playerId} onBack={() => setPlayerId(null)} />) : null}
      {tab === 'rooms' ? <RoomsTab api={api} lang={lang} guard={guard} /> : null}
      {tab === 'actions' ? <ActionsTab api={api} lang={lang} guard={guard} /> : null}
    </main>
  )
}
```
