# Bind Poker — Plan 3: `@bp/ui-kit` (shared React UI: game client, i18n, theme, poker table, lobby) — M7 shared part

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Implementers of Tasks 3, 5, 6 and 7 MUST load the `frontend-design:frontend-design` skill before writing components and follow the Design Brief below.

**Goal:** Build the edition-agnostic React library both web apps embed: a WebSocket game client (connection with reconnect, a pure reducer that applies the core protocol incrementally, a React hook/provider), i18n infrastructure with complete English and Vietnamese resources, a distinctive design system (tokens, primitives), the poker table (cards, seats, community, pot, turn timer, action bar, results), lobby components (room list, create/join), the two shared screens (Lobby, Room) plus a tiny hash router, and a playground page for visual iteration.

**Architecture:** `@bp/ui-kit` depends on `@bp/core` only (types, `filterEvent`-shaped events, `validateRoomConfig`, `HAND_CATEGORY_KEYS`, `ECONOMY`). It never imports `@bp/server-kit` — the client speaks the wire protocol from `packages/core/src/protocol/messages.ts` and the contract in `docs/server-kit.md` ("Reconnecting and frame order"). State lives in a pure reducer (`ClientState`) so it is unit-tested against the real engine: a test drives `@bp/core` hands and checks the reducer's view equals `playerView`. Components are presentational and take state + callbacks; the `useGameClient` hook is the only place that owns a socket. No edition knowledge: fonts, routes and features are decided by the consuming app.

**Tech Stack:** React 18.3, react-dom, i18next 23 + react-i18next 15, Vite 5 (playground only), Vitest 2 + jsdom + @testing-library/react 16, TypeScript 5.6, CSS Modules + CSS variables (no Tailwind, no UI framework). ESLint gains `eslint-plugin-react` for `react/jsx-no-literals`.

**Spec:** `docs/superpowers/specs/2026-09-04-bind-poker-design.md` §6.7 (FR-U01–U03), §16.6 (reconnect), §20 (protocol), §26 (i18n), §27 (responsive, screens 2–6, 12–13, table must-show list), §33; plus `docs/server-kit.md` "Wire contract" and "Reconnecting and frame order" (client rules).

## Global Constraints

- Node `>=22.13`, pnpm 9; in bash without pnpm: `export PATH="$PATH:$(npm prefix -g)"`.
- `@bp/ui-kit` `dependencies`: `@bp/core`, `react`, `react-dom`, `i18next`, `react-i18next`. Nothing else at runtime. Never imports `@bp/server-kit`, `ws`, Node built-ins, or anything under `apps/`.
- No hard-coded user-facing strings in JSX (`react/jsx-no-literals` with `noStrings: true`); every string comes from i18n keys that exist in BOTH `en` and `vi` (a test enforces key parity).
- The client never decides gameplay: it only renders `ServerMessage`s and sends `ClientMessage`s. `ACTION.baseSeq` is always the latest `seq` the client has applied. A `seq` that goes backwards, or a `STALE_STATE`/`INTERNAL "resync required"` error, sets `resyncNeeded` and the hook sends `RESYNC`.
- Reconnect: exponential backoff 1 s → 30 s (×2), auto `HELLO` when a token is configured, auto-`PONG` on `PING`.
- Accessibility floor: every control is a real `<button>`/`<input>` with an accessible name; cards expose `aria-label` (e.g. "Ace of spades"); focus rings visible; touch targets ≥ 44 px on mobile; colour never the only signal for turn/fold state.
- Responsive per spec §27.1: breakpoints 480/768/1024; the table switches to the vertical layout under 768 px; no horizontal page scroll.
- Test files colocated `src/**/*.test.ts(x)`; imports use explicit `.js` extensions (TS `moduleResolution: bundler` resolves `.js` → `.tsx`).
- Every commit message ends with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

## Design Brief (binding for all component tasks — load `frontend-design:frontend-design` first)

**Direction: "Đêm Sài Gòn" — a lacquered night card room.** Not a green-felt casino clone and not a generic dark dashboard.

- **Palette (tokens in Task 3):** ink navy ground `#0B1020` → `#141B33` gradient mesh with a faint grain overlay; **lacquer red** `#C8323C` and **antique gold** `#D9A441` as the only accents (gold = money/pot/turn, red = danger/fold/host); table surface a deep teal-black `#0F2A2E` with a subtle radial vignette and a thin gold rail; cards ivory `#F6F1E4` with near-black pips and lacquer-red hearts/diamonds; text `#EDE7D8` on dark, `#1B1F2E` on light panels. A light theme variant exists for lobby/profile screens (parchment `#F3EEE2` ground) — tokens only, same components.
- **Typography:** display `--font-display: "Fraunces", "Playfair Display", Georgia, serif` (numbers/pot/titles, optical size + slight italic for winners); body `--font-body: "Be Vietnam Pro", "Segoe UI", system-ui, sans-serif` (Vietnamese diacritics render correctly). ui-kit only references the variables; the app's `index.html` decides whether to load web fonts (Normal loads Google Fonts; Lite ships with the fallbacks — never a runtime check).
- **Motion (CSS only):** dealt cards flip in with a 60 ms stagger; the turn ring is a conic-gradient countdown; pot chips pulse once on `POT_UPDATED`; the winner seat gets a gold glow + the hand label slides up; community cards rise from the felt. `prefers-reduced-motion` disables all of it.
- **Composition:** the table is an ellipse with seats on the rim and the viewer's seat always at the bottom; the action bar is a lacquered tray anchored to the bottom edge on all sizes; lobby cards are asymmetric "tickets" with a perforated edge and a big mode glyph (♠ Hold'em / ⚄ Blind).
- **Restraint:** every effect must be cheap (no canvas, no JS animation loops); total ui-kit CSS ≤ 40 KB; keep components small and composable.

```ts
const flatten = (o: object, prefix = ''): string[] =>
  Object.entries(o).flatMap(([k, v]) => (typeof v === 'object' && v !== null ? flatten(v, `${prefix}${k}.`) : [`${prefix}${k}`]))

class MemoryStorage implements Storage {
  private m = new Map<string, string>()
  get length() { return this.m.size }
  clear() { this.m.clear() }
  getItem(k: string) { return this.m.get(k) ?? null }
  key(i: number) { return [...this.m.keys()][i] ?? null }
  removeItem(k: string) { this.m.delete(k) }
  setItem(k: string, v: string) { this.m.set(k, v) }
}

describe('locale resources', () => {
  it('en and vi have exactly the same keys in both namespaces', () => {
    expect(flatten(en).sort()).toEqual(flatten(vi).sort())
    expect(flatten(enCommon).sort()).toEqual(flatten(viCommon).sort())
  })
  it('cover every hand category, error code and action kind', () => {
    const keys = new Set(flatten(vi))
    for (const k of HAND_CATEGORY_KEYS) expect(keys.has(k)).toBe(true)
    for (const k of ['fold', 'check', 'call', 'bet', 'raise', 'allIn', 'play']) expect(keys.has(`actions.${k}`)).toBe(true)
    const common = new Set(flatten(viCommon))
    for (const code of ['NOT_YOUR_TURN', 'STALE_STATE', 'ROOM_FULL', 'SERVER_SHUTDOWN', 'INTERNAL']) expect(common.has(`errors.${code}`)).toBe(true)
  })
  it('has no empty strings', () => {
    for (const res of [en, vi, enCommon, viCommon]) for (const v of Object.values(flattenValues(res))) expect(String(v).trim()).not.toBe('')
  })
})

function flattenValues(o: object): Record<string, unknown> {
  const out: Record<string, unknown> = {}
  for (const [k, v] of Object.entries(o)) if (typeof v === 'object' && v !== null) Object.assign(out, flattenValues(v)) else out[k] = v
  return out
}

  it('prefers storage, then navigator, then vi', () => {

    expect(detectLanguage(s, 'vi-VN')).toBe('vi')
```

```ts
export const SUPPORTED_LANGUAGES = ['vi', 'en'] as const
export type Language = (typeof SUPPORTED_LANGUAGES)[number]
export const LANGUAGE_STORAGE_KEY = 'bp.lang'

const isLanguage = (x: unknown): x is Language => typeof x === 'string' && (SUPPORTED_LANGUAGES as readonly string[]).includes(x)

export function detectLanguage(storage: Storage | null, navigatorLanguage: string | undefined): Language {
  let stored: string | null = null
  try {
    stored = storage?.getItem(LANGUAGE_STORAGE_KEY) ?? null
  } catch {
    stored = null
  }
  if (isLanguage(stored)) return stored
  if (navigatorLanguage === undefined) return 'vi'
  return navigatorLanguage.toLowerCase().startsWith('vi') ? 'vi' : 'en'
}

export interface CreateI18nOptions {
  language?: Language
  storage?: Storage | null
  navigatorLanguage?: string
  /** Extra namespaces per language (e.g. the Normal app's `normal` namespace). */
  extraResources?: Partial<Record<Language, Record<string, object>>>
}

export function createI18n(opts: CreateI18nOptions = {}): i18n {
  const storage = opts.storage === undefined ? (typeof localStorage === 'undefined' ? null : localStorage) : opts.storage
  const language = opts.language ?? detectLanguage(storage, opts.navigatorLanguage ?? (typeof navigator === 'undefined' ? undefined : navigator.language))
  const instance = i18next.createInstance()
  instance.use(initReactI18next)
  void instance.init({
    lng: language,
    fallbackLng: 'vi',
    supportedLngs: [...SUPPORTED_LANGUAGES],
    defaultNS: 'game',
    ns: ['common', 'game', ...Object.keys(opts.extraResources?.vi ?? {})],
    resources: {
      en: { common: enCommon, game: enGame, ...(opts.extraResources?.en ?? {}) },
      vi: { common: viCommon, game: viGame, ...(opts.extraResources?.vi ?? {}) },
    },
    interpolation: { escapeValue: false },
    initImmediate: false,
    returnNull: false,
  })
  return instance
}

export async function setLanguage(instance: i18n, lang: Language, storage: Storage | null): Promise<void> {
  await instance.changeLanguage(lang)
  try {
    storage?.setItem(LANGUAGE_STORAGE_KEY, lang)
  } catch {
    /* storage unavailable */
  }
}

export function cardLabel(card: Card, t: TFunction): string {

export function errorLabel(code: ErrorCode, t: TFunction): string {

  return t(key) === key ? t('common:errors.INTERNAL') : t(key)
```

```ts
export function formatPoints(n: number, lang: Language): string {
  return new Intl.NumberFormat(LOCALE[lang], { maximumFractionDigits: 0 }).format(n)
}

export function formatCompactPoints(n: number, lang: Language): string {
  const abs = Math.abs(n)
  if (abs < 1000) return formatPoints(n, lang)
  const [value, suffix] = abs >= 1_000_000 ? [n / 1_000_000, 'M'] : [n / 1000, 'K']
  const digits = Number.isInteger(value) ? 0 : 1
  return `${new Intl.NumberFormat(LOCALE[lang], { minimumFractionDigits: 0, maximumFractionDigits: digits }).format(value)}${suffix}`
}
```

Reducer rules (the test below checks them against the real engine):
- `WELCOME` → `me`, `balance`, `serverTimeOffset = serverTime − now`, `replaced=false`. `ROOM_LIST` → `lobby`. `ROOM_SNAPSHOT` → `room`, `hand = handFromView(hand, room) | null`, `seq`, `deadlineAt`, `resyncNeeded=false`. `BALANCE` → `balance`. `NOTIFICATION` → append (ids increment). `ERROR` → `lastError`; `STALE_STATE` or `INTERNAL` whose message contains "resync" → `resyncNeeded=true`. `SESSION_REPLACED` → `replaced=true`. `ACK`/`PING` → unchanged. `leftRoom` → `room=null, hand=null`.
- `GAME_EVENT`/`ROOM_EVENT`: if `seq <= state.seq` and a room is loaded → `resyncNeeded=true` (still apply); set `seq`.
- Game events build/patch `hand` as a client-side mirror of `playerView`:
  `HAND_STARTED` → new hand from `room.players` (seats in `event.seats`, stacks from `RoomPlayerView.stack`, `displayName`), `pot = carryOverIn`, phase `BETTING` for holdem, for blind `DECISION` if `room.config.blind.decisionMode === 'playOrFold'` else `REVEAL`, `mySeat` = my room seat (null if not seated), `potPulse=0`.
  `BLINDS_POSTED` → per post: `stack −= amount`, `betThisStreet += amount`. `CARDS_DEALT` → `cardCount`, `holeCards` when `cards.length > 0`. `TURN_CHANGED` → `phase='BETTING'`, `actingSeat`, `legal` only for `mySeat`, `deadlineAt = event.deadlineAt ?? null`. `PLAYER_ACTED` → `stack`, `allIn`, `folded ||= kind==='fold'`, `betThisStreet += amount`, `lastAction`, `timedOut`; if `actingSeat === seat` → `actingSeat=null`, `deadlineAt=null`; if `seat===mySeat` → `legal=null`. `DECISION_PHASE` → `phase='DECISION'`, `actingSeat=null`, `legal` for my undecided seat = `{ seat, kinds:['play','fold'], callAmount: room.config.blind.fixedWager, minBet:0, maxBet:0, minRaiseTo:0, maxRaiseTo:0 }`, `deadlineAt`. `DECISION_MADE` → `hasDecided`; my seat → `legal=null`. `DECISIONS_REVEALED` → `decision`, `folded` for folds, `phase='REVEAL'`. `COMMUNITY_REVEALED` → `community`, all `betThisStreet=0`, `phase='REVEAL'`, `actingSeat=null`. `POT_UPDATED` → `pot`, `potPulse+1`. `SHOWDOWN` → `holeCards` for shown seats, `result.showdown`. `SETTLEMENT` → `stacks` into seats AND into `room.players`, `result={payouts,fee,showdown,carryOverOut,uncalledReturned,cancelled:false,reason:null}`, `phase='COMPLETE'`, `legal=null`, `actingSeat=null`, `deadlineAt=null`. `HAND_CANCELLED` → refunds added to stacks, `result.cancelled=true` with `reason`, `phase='COMPLETE'`. `HAND_COMPLETE` → `phase='COMPLETE'`.

```ts
import type { ClientMessage, ServerMessage } from '@bp/core'
import type { ConnectionStatus } from './types.js'

export interface SocketLike { /* as in Interfaces */ }
export type SocketFactory = (url: string) => SocketLike
export type AckOrError = Extract<ServerMessage, { t: 'ACK' }> | Extract<ServerMessage, { t: 'ERROR' }>
export const DEFAULT_BACKOFF_MS = [1000, 2000, 4000, 8000, 16000, 30000]
export interface ConnectionOptions { /* as in Interfaces */ }
export interface Connection { /* as in Interfaces */ }

const OPEN = 1

export function createConnection(opts: ConnectionOptions): Connection {
  const timers = opts.timers ?? { setTimeout: (fn: () => void, ms: number) => setTimeout(fn, ms), clearTimeout: (t: unknown) => clearTimeout(t as ReturnType<typeof setTimeout>) }
  const backoff = opts.backoffMs ?? DEFAULT_BACKOFF_MS
  const factory = opts.socketFactory ?? ((url: string) => new WebSocket(url) as unknown as SocketLike)
  let socket: SocketLike | null = null
  let status: ConnectionStatus = 'idle'
  let token = opts.token ?? null
  let manualClose = false
  let attempt = 0
  let reconnectTimer: unknown = null
  let reqCounter = 0
  const pending = new Map<string, { resolve: (m: AckOrError) => void; reject: (e: Error) => void; timer: unknown }>()

  const setStatus = (s: ConnectionStatus, reason?: string) => { status = s; opts.onStatus(s, reason) }
  const failPending = (why: string) => { for (const [id, p] of pending) { timers.clearTimeout(p.timer); p.reject(new Error(why)); pending.delete(id) } }

  const open = () => {
    manualClose = false
    if (reconnectTimer !== null) { timers.clearTimeout(reconnectTimer); reconnectTimer = null }
    setStatus(attempt === 0 ? 'connecting' : 'reconnecting')
    const ws = factory(opts.url)
    socket = ws
    ws.onopen = () => {
      attempt = 0
      setStatus('open')
      if (token) ws.send(JSON.stringify({ t: 'HELLO', sessionToken: token } satisfies ClientMessage))
    }
    ws.onmessage = (ev) => {
      let msg: ServerMessage
      try { msg = JSON.parse(String(ev.data)) as ServerMessage } catch { return }
      if (msg.t === 'PING') { ws.send(JSON.stringify({ t: 'PONG' })); return }
      if (msg.t === 'SESSION_REPLACED') manualClose = true
      if ((msg.t === 'ACK' || msg.t === 'ERROR') && msg.reqId !== undefined) {
        const p = pending.get(msg.reqId)
        if (p) { pending.delete(msg.reqId); timers.clearTimeout(p.timer); p.resolve(msg) }
      }
      opts.onMessage(msg)
    }
    ws.onerror = () => { /* onclose follows */ }
    ws.onclose = (ev) => {
      if (socket !== ws) return
      socket = null
      failPending('connection closed')
      if (manualClose) { setStatus('closed', ev.reason || undefined); return }
      const delay = backoff[Math.min(attempt, backoff.length - 1)]!
      attempt += 1
      setStatus('reconnecting', ev.reason || undefined)
      reconnectTimer = timers.setTimeout(() => { reconnectTimer = null; open() }, delay)
    }
  }

  return {
    get status() { return status },
    connect() { if (socket) return; attempt = 0; open() },
    disconnect() {
      manualClose = true
      if (reconnectTimer !== null) { timers.clearTimeout(reconnectTimer); reconnectTimer = null }
      const ws = socket
      socket = null
      failPending('disconnected')
      if (ws) ws.close(1000, 'bye')
      setStatus('closed')
    },
    setToken(next) { token = next },
    send(msg) { if (!socket || socket.readyState !== OPEN) return false; socket.send(JSON.stringify(msg)); return true },
    request(msg) {
      return new Promise<AckOrError>((resolve, reject) => {
        if (!socket || socket.readyState !== OPEN) { reject(new Error('not connected')); return }
        const reqId = `q${++reqCounter}`
        const timer = timers.setTimeout(() => { pending.delete(reqId); reject(new Error(`request ${msg.t} timed out`)) }, opts.requestTimeoutMs ?? 10_000)
        pending.set(reqId, { resolve, reject, timer })
        socket.send(JSON.stringify({ ...msg, reqId }))
      })
    },
  }
}
```

```tsx
export function useGameClient(opts: { url: string; token?: string | null; autoConnect?: boolean; socketFactory?: SocketFactory }): GameClientApi {
  const [state, dispatch] = useReducer(reduceClient, initialClientState)
  const stateRef = useRef(state)
  stateRef.current = state
  const connection = useMemo(() => createConnection({
    url: opts.url,
    token: opts.token ?? null,
    ...(opts.socketFactory ? { socketFactory: opts.socketFactory } : {}),
    onMessage: (msg) => dispatch({ type: 'server', msg, now: Date.now() }),

    return () => connection.disconnect()

  }, [state.resyncNeeded, state.status, connection])
```

```ts
export function ringPositions(seatOrder: number[], anchorSeat: number | null): Map<number, { x: number; y: number }> {
  const n = seatOrder.length
  const out = new Map<number, { x: number; y: number }>()
  if (n === 0) return out
  const anchorIdx = anchorSeat === null ? 0 : Math.max(0, seatOrder.indexOf(anchorSeat))
  for (let i = 0; i < n; i++) {
    const rel = (i - anchorIdx + n) % n
    const angle = Math.PI / 2 + (rel * 2 * Math.PI) / n // anchor at bottom, clockwise = increasing angle (screen y grows downward)
    out.set(seatOrder[i]!, { x: 50 + 42 * Math.cos(angle), y: 50 + 38 * Math.sin(angle) })
  }
  return out
}
```
